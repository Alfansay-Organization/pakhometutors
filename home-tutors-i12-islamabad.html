Turn a Failed Mock into a Three-Item Action List

A low mock score feels final. Treated well, it is a map. The goal is not to feel bad about the mark — it is to extract three actions you will actually do.

Process within 24 hours

  1. Mark the paper honestly.
  2. Tag each lost mark: misread / method / memory / time / carelessness.
  3. Write only three actions for the next two weeks.

Example action list

  • Practise five “explain” questions with evidence underlines
  • Rebuild the quadratic formula from memory daily for seven days
  • Do one timed 20-minute mixed set every other day

More than three actions usually means none get done. Students using home tutors in I-12 Islamabad can bring the three-item list to the next session so tuition targets the real gaps.
