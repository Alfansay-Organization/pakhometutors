Re-Reading Notes vs Testing Yourself: Which Actually Builds Memory

Re-reading feels productive because the page looks familiar. Familiarity is not the same as recall. Self-testing forces the brain to retrieve, which strengthens the memory for next time.

A fair comparison

  1. Study a short section
  2. Close the book and write three facts or steps from memory
  3. Check — whatever you missed was only recognised, not owned
