Teach It to Someone Else: The Fastest Way to Find What You Only Half-Know

Explaining a topic forces complete sentences. Gaps appear as soon as you say “and then you just…” without knowing the next step. You do not need a real class — a sibling, parent, or empty chair works.

Five-minute teach-back

  1. Pick one idea from today’s lesson.
  2. Explain it aloud without notes for three minutes.
  3. Invite one question from the listener (or invent one yourself).
  4. Note any hesitation; that is tonight’s micro-revision.

Example

Teaching “balanced forces”: if you cannot give a everyday example (book resting on a table) and state that forces cancel so motion does not change, the definition is still incomplete.
