How a Decision Tree Makes a Choice Without Thinking Like a Human

Many “AI” systems used in class projects are decision trees: a sequence of yes/no questions that route an input to a label. There is no understanding — only rules learned or written down.

Tiny example

Is temperature > 30°C? → Yes → “Hot day”. No → Is it raining? → Yes → “Wet day”. No → “Mild day”.

Each answer follows one branch. The tree never “knows” weather; it only applies thresholds. Modern models are more complex, but mapping inputs to outputs through structure remains.
