The Chain Rule: Differentiating a Function of a Function

When y depends on u and u depends on x, a small change in x changes u, which then changes y. The chain rule multiplies those rates: dy/dx = (dy/du) × (du/dx).

Example

y = (3x + 1)⁵. Let u = 3x + 1, so y = u⁵. Then dy/du = 5u⁴ and du/dx = 3, so dy/dx = 5(3x + 1)⁴ × 3 = 15(3x + 1)⁴.

Think of a gear train: the overall ratio is the product of the individual ratios.
