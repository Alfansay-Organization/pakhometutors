Build a Personal Formula Sheet You Will Actually Use

Copying every formula from the textbook creates a dense sheet nobody reviews. A personal formula sheet should be short, tested, and written in your own layout.

Rules for the sheet

  • Only formulas you have used in a real question
  • One tiny example or unit note beside each formula
  • Group by topic (motion, electricity, algebra…)
  • Rebuild the sheet from memory once a week; fix gaps

Example line

v = u + at — use when acceleration is constant; units m/s, m/s², s

If you cannot explain when to use a formula, it does not yet belong on the sheet — study the condition first.
