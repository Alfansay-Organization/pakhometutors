Why Python Cares About Indentation

In many languages, braces mark code blocks. In Python, indentation is the block structure. Code at the same indent level belongs together; a deeper indent means “inside” the previous line’s control structure.

Why it helps

  • Forces readable layout
  • Makes nesting visible at a glance
  • Catches some logic mistakes early (wrong indent = wrong block)

Mixing tabs and spaces can break programs in confusing ways — pick one style and stay consistent (spaces are the usual recommendation).
