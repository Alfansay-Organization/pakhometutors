The One-Sentence Summary Test for Anything You Just Read

Highlighting a whole page creates the feeling of study without proving understanding. A stricter test is simple: close the book and write one sentence that captures the main point. If the sentence is empty or vague, the reading did not stick.

How to run the test

  1. Read one section or worked example once.
  2. Close the book.
  3. Write one sentence: “This section says that…”
  4. Open the book and compare. Fix the sentence until it is accurate and specific.

Weak vs strong summaries

Weak: “This page is about photosynthesis.”

Strong: “Photosynthesis uses light energy to turn carbon dioxide and water into glucose and oxygen in the leaves.”

The strong version can be used later for revision. The weak version cannot.

Use it across subjects

  • Maths: “This method isolates the variable by doing the same operation on both sides.”
  • History: “The main cause emphasised here is… because…”
  • English: “The writer’s purpose in this paragraph is to…”

Tonight
