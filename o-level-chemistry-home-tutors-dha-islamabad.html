A Systematic Way to Balance Chemical Equations

Balancing is conservation of atoms: the same elements in the same counts on both sides. Guessing coefficients randomly wastes time.

Order that usually works

  1. Write correct formulae first — never change a formula to “fix” balance
  2. Balance metals, then non-metals, then hydrogen, then oxygen
  3. Leave elements that appear in several compounds until last when needed
  4. Check every element; multiply through if you used a half coefficient

Example: H₂ + O₂ → H₂O becomes 2H₂ + O₂ → 2H₂O after oxygen is balanced.
